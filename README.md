# SocialOS

**A Strategic Social Intelligence Simulator for Analytical Minds**

SocialOS is a web-based social skills training system designed for Young Adults with ASD who think analytically and are missing the Operating System of Social Cues. Instead of expecting users to "pick up" social cues intuitively, it teaches social dynamics as learnable systems — pattern recognition, status dynamics, energy management, and influence engineering. This system has been designed by an ASD father for his ASD son, learning from life-long shared experiences, social mis-steps and recoveries.

## Features

- **Branching scenario simulations** — make choices, see consequences, understand why
- **Emotion Scan mechanic** — identify emotional drivers before responding
- **Signal analysis** — see what each choice signals to others
- **AI-powered debrief** — analytical coaching after each scenario (powered by Claude)
- **Energy & XP system** — social interaction has a real cost; manage it
- **Reputation tracking** — your patterns shape how others perceive you

## Tech Stack

- React + Vite
- Claude API (Anthropic) for AI coaching debrief

## Getting Started

```bash
npm install
npm run dev
```

## Curriculum

- **Level 1: Social Physics** — How humans actually make decisions
- **Level 2: Tactical Interaction** — Team dynamics, authority, friendship
- **Level 3: Advanced Strategy** — Influence, conflict resolution, energy management
- **Level 4: Mastery Mode** — Dynamic scenarios with memory and reputation
